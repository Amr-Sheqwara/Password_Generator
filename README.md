# Password_Generator

This is as the title implies a Password generator and in addition i added a password strength reviewer and about us page!

## 🛠️ Built With

This project is built using purely vanilla web technologies, requiring no external libraries or frameworks:

* **HTML5:** Semantic structure and layout.
* **CSS3:** Custom variables, flexbox, CSS transitions, and radial gradients for a modern dark mode aesthetic.
* **JavaScript (Vanilla):** DOM manipulation, clipboard API integration, and mathematical entropy calculations for password strength.
